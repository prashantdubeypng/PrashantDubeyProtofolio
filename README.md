# Prashant Dubey - Developer Portfolio

A next-generation animated developer portfolio built with React Router, Tailwind CSS, and Framer Motion. Features premium glassmorphism design, 3D interactions, and smooth 60fps animations.

![React Router](https://img.shields.io/badge/React_Router-v7-blue?style=flat-square)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-v4-06B6D4?style=flat-square)
![Framer Motion](https://img.shields.io/badge/Framer_Motion-v12-purple?style=flat-square)

## ✨ Features

- **Premium Animations** - Smooth 60fps animations with consistent easing
- **3D Tilt Cards** - Interactive cards with perspective transforms on hover
- **Glassmorphism Design** - Modern frosted glass UI with depth
- **Dark Theme** - Eye-friendly dark mode with emerald/teal/cyan accents
- **Interactive Elements** - Robot avatar with eye tracking, robot dog companion
- **Typewriter Effect** - Animated name reveal in hero section
- **Focus Mode** - Click projects to highlight with backdrop blur
- **System Architecture Visualization** - Animated data flow diagrams for projects
- **Responsive Design** - Fully responsive across all devices

- **Framework**: React Router v7 with Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Language**: TypeScript

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
```
